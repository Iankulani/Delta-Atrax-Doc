📦 Install with Git

Follow these steps in order. Commands work on Linux, macOS, and Windows (Git Bash / PowerShell).

1

Install Git

Check whether Git is already installed.

$ git --version

If missing: sudo apt install git (Debian/Ubuntu), brew install git (macOS), or git-scm.com (Windows).

2

Choose a folder

Open a terminal where you want the tool.

$ cd ~/tools
3

Clone the repository

Download Delta Atrax V2 from GitHub.

$ git clone https://github.com/Iankulani/delta-atrax-v2.git
4

Enter the project folder

$ cd delta-atrax-v2
5

Install dependencies

Optional virtual environment first, then requirements.

$ python3 -m venv venv && source venv/bin/activate $ pip install -r requirements.txt
6

Update later

Pull the newest version any time.

$ git pull origin main
💡 Replace YOUR-USERNAME with the real GitHub account or organisation that hosts Delta Atrax V2.

🕸️ How to Run

From inside the delta-atrax-v2 folder:

🚀

Start the tool

$ python3 delta_atrax_v2.py
❓

See all options

$ python3 delta_atrax_v2.py --help

⚠️ command not found

Install Python 3.7+ and required system tools (nmap, curl, wget, netcat).

📦 Module missing

Re-run pip install -r requirements.txt.

🔒 Permission denied

Use a virtual environment or run with sudo for raw sockets.
